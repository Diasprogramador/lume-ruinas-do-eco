# Trilha e efeitos de Lume

Áudio original composto e sintetizado para este projeto, sem samples de terceiros.

- **Jardins do Eco** (`gardens.wav`): 53,33 segundos, 72 BPM, pads suaves, baixo e sinos em estéreo, loop contínuo para exploração e menu.
- **Guardião do Eco** (`guardian.wav`): 17,78 segundos, 108 BPM, arpejos e percussão, loop contínuo para a arena.
- Quinze efeitos individuais: corte, acerto, ataque carregado, explosão de impacto, magia, explosão ascendente, mergulho, carga pronta, sementes, santuário, seleção, compra, dano, pulo e dash.

O jogo cruza as duas faixas suavemente e mantém a música durante a pausa, com redução de volume. Música e efeitos têm canais e controles independentes.

Para regenerar os arquivos: `python tools/compose_audio.py`. Somente biblioteca padrão do Python; nenhuma instalação adicional é necessária.
